# Traductions

- 10 langues : fr, en, de, es, it, pl, pt (Brésil), ru, uk, cs. `fr.ts` **définit** les clés (`TranslationKey`) ; les autres
  fichiers sont des `Record<TranslationKey, string>` : une clé ajoutée en français et oubliée ailleurs casse le
  typecheck, c'est le garde-fou. Ajoute toujours la clé dans les 10 fichiers dans le même changement.
- Le texte des cartes suit les **termes officiels de chaque édition** de Zombicide 2e édition (noms des zombies,
  « Extra Activation », « Rush », niveaux de Danger). Ne traduis pas librement un terme de jeu : si tu ne connais pas
  le terme officiel dans une langue, signale-le à l'utilisateur au lieu d'inventer.
- Paramètres entre accolades (`{n}`, `{level}`) : mêmes noms dans toutes les langues. Formes propres au titre Rush
  (`zombie.<type>.rush`) et à « Tous les … » (`zombie.<type>.all`) quand la langue l'exige.
- `translations.ts` importe les fichiers avec l'extension `.ts` : il est chargé par les tests sous Node.
- Typographie : reprends celle déjà utilisée dans le fichier de la langue (guillemets, apostrophes, espaces avant
  la ponctuation) plutôt que d'en introduire une autre.
- Les textes doivent tenir à l'écran en paysage sur un petit téléphone : une traduction nettement plus longue que
  l'anglais (allemand, russe) se vérifie à l'écran.
- `store/listing.md` : fiche des stores, limites titre 30, description courte 80, longue 4000 caractères.
- Une correction de texte seule part en OTA (`/release`), sans nouvelle version sur les stores.
